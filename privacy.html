Privacy Policy – OpenClaw (Personal)

Last updated: November 17, 2026

1. Who uses this app

OpenClaw (Personal) is used solely by its owner. It is not distributed to, or used by, any other person.

2. Data accessed

With the owner's consent through Google OAuth, the app accesses only the owner's own Google account data within the permissions (scopes) granted, such as Gmail messages and Google Calendar events.

3. How data is used

Data is used only to perform tasks requested by the owner (for example, summarizing, organizing or drafting emails and calendar entries). Data is not sold, shared with third parties, or used for advertising.

4. Storage and security

OAuth tokens and any processed data are stored only on the owner's personal device and are protected by the device's security controls.

5. Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

개인정보처리방침 – OpenClaw (Personal)

최종 수정일: 2026년 11월 17일

1. 사용자

본 앱은 소유자 본인만 사용하며, 다른 사람에게 배포되거나 제공되지 않습니다.

2. 접근하는 정보

Google OAuth를 통한 소유자의 동의 하에, 부여된 권한 범위 내에서 소유자 본인의 Google 계정 정보(Gmail, Google 캘린더 등)에만 접근합니다.

3. 이용 목적

소유자가 요청한 작업(이메일·일정의 요약, 정리, 초안 작성 등)을 수행하는 데에만 이용하며, 판매·제3자 제공·광고 목적으로 이용하지 않습니다.

4. 보관 및 보안

OAuth 토큰과 처리된 정보는 소유자의 개인 기기에만 보관되며, 해당 기기의 보안 설정으로 보호됩니다.

5. Google API 서비스 사용자 데이터 정책

본 앱은 Google API로부터 받은 정보를 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책에 따라 이용합니다.

6. 접근 권한 철회

https://myaccount.google.com/permissions 에서 언제든지 접근 권한을 철회할 수 있습니다.
